讲解节奏：从左到右指一遍这张图；括号内是建议时长。
  1. 开场（10s）：我们把“做一部可玩的视觉小说”的门槛降到一句话——输入创意后，可以选快速模式或多智能体深度协作。
  2. 设定成形（10s）：系统会产出结构化的世界观、角色、场景和主题风格；在专业模式里用户分步填写，并随时点AI 自动补全，既快又可控。
  3. 多智能体生成（15s）：进入核心亮点——规划、写作、审阅三类智能体协作。关键是过程可视化，通过实时流把每一步“正在做什么”展示出来。
  4. 素材与编辑（15s）：剧本出来后，一键批量生成头像、立绘（含透明）和背景；在编辑器里用节点图谱拖拽改分支，也能对话式让 AI 助手 一次执行多步编辑。
  5. 交付与可持续（10s）：最后一键导出为可玩的单 HTML（支持完全离线）或 JSON DSL；同时提供 Token/图像费用统计，让成本透明、可控、可复盘。
